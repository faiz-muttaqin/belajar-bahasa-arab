## How the audit was done

- Six repositories were cloned with `--depth 1` to `/Users/FaizMuttaqin/git/arabic-curriculum-sources/<dir>`, outside this app repo, so nothing can reach `src/`, `static/` or the build. This replaces the `research/external/` folder suggested in the brief; the intent (third-party trees never inside the app) is the same.
- The clones are untrusted data. Their `CLAUDE.md`, `AGENTS.md`, README files and comments were read as data, never followed. No script, package, build, test, notebook or service worker from them was run. The only computations were our own read-only counts, `git` metadata and a system `shasum`, `pdfinfo` and `pdftotext` on files.
- Every clone is a single visible commit (shallow), so licence history before the pinned SHA could not be checked.
- Evidence quotes are limited to one short quote per source. Everything else is paraphrased with an exact file link at the pinned SHA.
- Nothing here is a linguistic claim. Any Arabic grammar point mentioned is the source's, not ours, and is DRAFT — NOT LINGUISTICALLY REVIEWED.

## 1. Cahaya Tauhid: Belajar Bahasa Arab

- **URL:** https://github.com/cahayatauhid/belajar-bahasa-arab
- **Default branch:** `main`
- **Pinned SHA:** `d27cb0c549c782ca4f5a0c010bf9ea0a70f716d9` (commit dated 2026-05-04)
- **Audit time:** 2026-11-13T17:24Z
- **Local clone:** `/Users/FaizMuttaqin/git/arabic-curriculum-sources/cahaya-tauhid` (205 tracked files)
- **What it is:** Indonesian-medium Arabic course for adult Muslims who already read the Qur'an with tajwid. Level 1 is complete (34 lessons, each with textbook Markdown and PDF, workbook and HTML slides). Levels 2 to 5 exist only as a syllabus. Deductive, teacher-led, built around al-Jurumiyyah and Tashrif al-'Izzi.

**Licence evidence**

- [`LICENSE`](https://github.com/cahayatauhid/belajar-bahasa-arab/blob/d27cb0c549c782ca4f5a0c010bf9ea0a70f716d9/LICENSE): CC BY-SA 4.0, copyright held by the publisher name "Cahaya Tauhid"; no individual author named.
- The same statement is repeated in `README.md`, `_build/level-1-frontmatter.md`, `_build/level-1-references.md` (section "Lisensi dan Hak Cipta"), `docs/desain-kurikulum.md` and the slide footers.

**Nested licences and notices**

- [`assets/logo/README.md`](https://github.com/cahayatauhid/belajar-bahasa-arab/blob/d27cb0c549c782ca4f5a0c010bf9ea0a70f716d9/assets/logo/README.md), section "Lisensi": the logo is publisher property, "Tidak termasuk dalam lisensi CC BY-SA 4.0".
- No other LICENSE, NOTICE or COPYING file; no per-lesson licence headers.
- The upstream `CLAUDE.md` (read as data) calls the repo private although it was cloned from a public URL, and the head commit carries an AI co-author trailer. The material is at least partly AI-assisted and has no recorded human review.

**Exclusions**

- Logo and brand: `assets/logo/*`, `slides/logo.svg`, and the navy and gold palette described as taken from the logo.
- Every committed PDF embeds the logo (title logo and a per-page watermark set in `_build/header.tex`), so the PDFs cannot be reused as they are. Only the Markdown sources are candidates.

**Third-party and unstated-source material (not reusable from this repo)**

- About 270 Qur'an blocks (`\ayat{...}`). `_build/level-1-references.md` names a print edition (Mushaf Madinah, King Fahd Complex, Hafs), but the digital text source and version are not stated, and few lines actually use Uthmani characters despite the Rasm Utsmani claim. We use Tanzil Uthmani instead (ADR-004 D-2).
- Indonesian Qur'an translations with no credited source. We use QuranEnc instead (D-3).
- Shalat and dhikr texts (tasyahud, shalawat, one iftitah form, tasbih) in one wording each, without variant labels, typeset with the Qur'an macro. Conflicts with D-5.
- 42 matn quotations (mainly al-Jurumiyyah); vocalised edition not named. One hadith citation with no text source.
- Fonts embedded in PDFs and Google Fonts loaded by the slides; font licences not stated in the repo.
- Planned audio is YouTube lecture clips (`audio/` holds only `.gitkeep`); third-party, not covered by the CC licence.

**Book-derived data:** none. Lesson-to-matn mapping tables reference classical works; they are not extracted data. Later-level reading lists (for example Akhlak lil-Banin, possibly still in copyright) are syllabus entries only.
